## ☯️ 概念建模

### [[五邪]]（难经第10难）
| 邪气类型 | 病理来源 | 五行关系 | 治法 |
| :--- | :--- | :--- | :--- |
| **正邪** | 心脏本身发病 | 本经自病 | 直接治心 |
| **虚邪** | 肝病影响心脏 | 母病及子（木→火） | 虚则补其母（补肝） |
| **实邪** | 脾病影响心脏 | 子病累母（土←火） | 实则泻其子（泻脾） |
| **微邪** | 肺病逆袭心脏 | 被克者反噬（金→火） | 轻微调理 |
| **贼邪** | 肾病克伐心脏 | 相克关系加剧（水克火） | 强力干预 |

- **临床应用**：
  - 肝癌长实瘤 → 补肾（水）→ 肝木自动释放能量生火 → 肿瘤缩小（"母能令子虚"）。
  - 心脏虚弱 → 不泻心，而是补肝（"虚则补其母"）。

### [[月经]]与[[奶水]]
- **核心逻辑**：女人的奶水 = 女人的月经（同源异位）。
- **生成路径**：
  ```
  [[脾脏]]（受五味）→ [[肺脏]]（化为白色奶水）→ [[心脏]]（火克金，集中于乳房）→ 顺[[阳明经]]下行 → [[小肠]]（火蒸煮）→ 变红排出 = 月经
  ```
- **诊断法则**：
  - 月经颜色很淡 → [[小肠]]火不够 = 寒症。
  - 月经颜色很深/黑 → 小肠火太旺 = 热症。

```
怒而伤肝 → 肝损更易怒 → 饮酒解愁 → 酒精再伤肝 → 暴怒频发 → 肝硬化/肝癌
```
